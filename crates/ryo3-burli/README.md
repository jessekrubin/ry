# `ryo3-burli`

ryo3-wrapper for `burli-encode` crate (Brotli compression)

`ry.brotli_compress(data, level=5)` accepts compression levels `0` through `5`.
Decompression lives in `ryo3-brotli` (`ry.brotli_decompress`).
